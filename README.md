# Smart ANPR System

Automatic Number Plate Recognition using YOLO12 and OCR.

## Features

- Vehicle number plate detection
- OCR-based text recognition
- Vehicle tracking
- Plate logging
- Video processing

## Tech Stack

- Python 3.10
- Ultralytics YOLO12
- OpenCV
- EasyOCR/PaddleOCR
- CVZone

## Run

pip install -r requirements.txt

python test.py
